# Offline artifact rollback rehearsal

Verified 14 October 2026 with Node 24.14.0. Run `node --import tsx scripts/verify-artifact-rollback.ts` from the repository root with the existing reviewed GeoNames and `.data/era5/tiles-2025-v3` installed. Missing actual history/index is a failure, not a synthetic success or skipped actual-source claim. The script makes no provider request or historical download.

It pins the existing public 59-node real OSM fixture (`tests/osm/fixtures/real-three-boxes/candidates.json`, SHA256 `7d07f347d8e5dfff06cdfc59a72e262b61760528bd5cac14b091f75e26f23755`) and actual three-place 2025 tiled climate manifest (SHA256 `9ffc58e9033984b235241525471d4e5b6571a6f1640147502b57d014c31181e8`). Three fresh Node processes per artifact serve loopback MCP: accepted previous, rejected temporary checksum-corrupt candidate, restored original. All six processes passed; restored structured output was identical and source hashes unchanged. Climate verified Kodaikanal January's 294 valid hourly dark-time samples and retained partial/sample-only status. Corrupt climate returned unavailable without statistics; corrupt candidates returned an error without candidate content. Paths were absent from responses.

Overrides `--candidate`, `--candidate-sha256`, `--climate`, `--climate-sha256` require reviewed hashes; the named-place/count assertions intentionally remain this rehearsal's fixed probes. A different regional artifact needs a separately reviewed representative place/count, not relaxed acceptance. The tiny OSM fixture and 2025 history do not prove regional/global capacity, complete baseline coverage or selected-host rollback.

Temporary corruption uses a separate file; the original manifest and referenced tiles remain immutable. Original configuration is supplied in fresh child environments, so stale process caches cannot mask restore behavior. Only the verified temporary directory is removed. No active release pointer is changed.

For an actual host, retain complete previous code/config and artifact path/digest pairs. Verify the candidate's trusted manifest, referenced tile hashes/bytes and ODbL version offer before switching. Switch code/config and both artifact selections together, restart, and run health plus representative tools. On failure restore the previous selections and restart before traffic. Measure actual disk headroom, cold/warm/concurrent latency, RSS, proxy logs and streaming on the selected host. Never accept a newly computed digest merely to bypass failure. See [deployment](deployment.md).
