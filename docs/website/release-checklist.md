# Publication checklist

This is a local preview, not a published release. The release command refuses incomplete approvals.

- [ ] Public NightSky listing URL and tested setup supplied (not required for a truthful unavailable-listing site).
- [ ] Operator identity, hosting and data recipients confirmed.
- [ ] Logged fields, retention, deletion process and analytics/cookies confirmed.
- [ ] Released source inventory, coverage and forecast horizons approved.
- [ ] News-content reuse and existing image/video rights confirmed.
- [ ] Privacy/Terms reviewed, effective dates and approval recorded.
- [ ] Actual host confirmed; Netlify function routing validated locally against that host before deployment.
- [ ] Hero video public-delivery optimization evaluated.
- [ ] Owner reviews local preview and authorizes any publication separately.

No plugin change is needed to gather these facts. No deployment, push or marketplace action was performed.
