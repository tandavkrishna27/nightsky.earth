This compact derivative contains 134 named candidate nodes/complete ways from Geofabrik Bhutan. Raw source is ignored and not retained here. `manifest.json` records exact source URL, source digest, UTC retrieval time, vintage, geometry policy, artifact digest, and measured desktop build limits. See `docs/operations/offline-extract-wave.md` for the bounded acquisition/build process, repeatability evidence, exclusions, and private-repository public-offer release gate.

The artifact is partial coverage; relations excluded, ways are vertex-mean points with unknown entrances. All access, opening, permission, safety, and darkness remain unknown. Names are untrusted OSM data. It is not a dark-sky ranking.
