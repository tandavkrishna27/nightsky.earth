## Full historical-grid dependency

The legacy flat format has a 10,000-pair release limit. The bounded hierarchy and lineage implementation now have synthetic capacity evidence for the proposed 56,039 named-place pairs; this is not complete quarter-degree whole-world history. Actual required coverage, acquisition feasibility and real release measurements remain prerequisites for production acceptance. An incrementally covered-cell release is an owner decision with explicit not-covered responses; this sequence accepts no scope reduction. Neither path changes the existing scientific completeness rules.

There is no fixed number of acquisition waves or defensible total ETA until actual source limits, throughput and final coverage are measured. Failed source admission can require a bounded correction; it does not justify repeatedly reopening completed generic components. Each wave must name concrete original acceptance evidence it advances.
