# Invited pilot measurement plan

Prepared 13 October 2026. No testers have been invited, contacted or measured. This plan is ready for use after the authorized release or an authorized staging usability check. It is a small usability pilot, not a representative global market study.

Recruit, when explicitly authorized, a small mix of astronomy-app users, beginners, meteor/event observers and astrophotographers across hemispheres/time zones where feasible. Include the owner's own planning use. Record each group's sample size and the current multi-app workflow as baseline. Do not infer participant identity from tool calls.

| Measure | Definition / denominator | Collection boundary |
|---|---|---|
| Installs | Host-reported installs for stated window | Report only if exposed; otherwise unavailable |
| Activations | Host-exposed activation definition | Separate from installs and calls |
| Tool calls | Aggregate calls and success/error counts by tool and day | No raw prompt, place, coordinate, subject/session or IP histories |
| Latency | Aggregate p50/p95 and sample count, stated window | Report measurement method and missing data |
| Coverage/source failures | Aggregate available/partial/not-covered/failure counts | Never infer that unavailable means clear sky |
| Links | Aggregate outbound link counts only if exposed and disclosed | No person-level browsing history |
| Useful completed plans | Voluntary feedback count / respondents, journey type | Separate observed completion from self-report |
| Changed decision | Voluntary place/time/activity/preparation/app-switch feedback / respondents | No precise place or personal itinerary |
| Return use | Voluntary report / respondents or a host-exposed aggregate | Never infer unique people or retention from anonymous calls |

Feedback prompt: Did the plan help you choose a place, time, activity or preparation? Did it reduce switching between apps? Which missing evidence mattered? Would you use it again? Sharing feedback is optional; ask participants to omit exact locations and personal details. Record observed behavior separately from stated preference. Summarize themes after consent and minimization; do not create individual query histories.

Use [pilot findings template](pilot-findings-template.md) to report counts, denominators, journey signals, source gaps, limitations and a continue/change/stop recommendation. Choose a feedback retention period and deletion route before collecting responses, matching the verified disclosures. Owner scope decisions remain separate from pilot recommendation.
