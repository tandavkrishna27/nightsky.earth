## Review findings resolved

1. Malformed selected OSM IDs/tags/names previously fell through a permissive importer. Strict regional validation, duplicate rejection and count preservation now prevent silent source-row loss; the actual artifact hash is unchanged.
2. Historical post-import recovery used the 2025 manifest, leaving completed local data blocked by an unresolved remote ledger. Approved-plan-aware reconciliation now proves job/source identity offline and permits subsequent work without resubmission.
3. Historical publication compared only source revisions, allowing altered metadata to replace a revision. Exact canonical object **and byte** equivalence is now required for an idempotent rerun; changed time, mapping, index vintage or whitespace fails without replacing prior bytes.
4. Calendar presence previously made an event factor favorable even when its visibility was not evaluated or it was below the horizon. Reproducing tests now require visibility-aware factors.

Independent review reported no remaining actionable findings in frozen lane/integration code. Windows-created CRLF skill files exposed a frontmatter assertion that assumed LF; the assertion now accepts valid LF/CRLF, while package source files and Git checkout remain normalized to LF.
