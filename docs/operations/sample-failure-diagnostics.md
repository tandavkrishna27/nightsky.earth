# Future sample worker failure diagnostics — 16 October 2026

The completed remote job without a local raw file cannot be diagnosed retroactively from its successful checkpoint. `sample_live.supervise` discards child stdout/stderr, and result metadata parsing, size admission and asset-origin checks occur before `sample.raw` creation. No historical cause is asserted and no historical output is modified.

For future separately authorized attempts, `sample_live.execute` now writes an exclusive `failure-diagnostic.json` on a caught worker failure when its existing output root and storage allowance permit. The receipt contains only schema version and fixed-enum phase/error categories. It records no exception text, job identity, URL, response body, path, credential or arbitrary upstream value. Result JSON/shape/size/origin, HTTP metadata, download and decode stages remain distinguishable. An origin rejection does not approve that origin. Generic executor/stream/decode failures retain generic categories rather than guessing causes.

The receipt is at most 256 bytes, counted within the existing 128 MiB tree cap, and never overwrites prior evidence or creates an output root. A missing receipt remains possible on forced termination, storage exhaustion, invalid/absent root or filesystem failure; it is not success. Checkpoints, one-submission allowances, deadlines, no-retry behavior, host admission and supervisor containment are unchanged. Existing historical source pins identify the historical execution; any future allowance must separately bind the new source revision.

Offline tests first demonstrated the absent receipt. All 26 sample adapter tests pass with the retained `.data/era5/venv/Scripts/python.exe` interpreter, including synthetic NetCDF containment. Default system Python lacks netCDF4 (24 other tests passed); no dependency was installed. Tests inject local responses and failures for origin, JSON, shape, size, transport, stream and decode, test secret exclusion, reject arbitrary categories, preserve existing receipt bytes and enforce the storage cap. The complete ERA5 offline suite passes 149 tests. No network, remote retries or historical output writes were performed.
