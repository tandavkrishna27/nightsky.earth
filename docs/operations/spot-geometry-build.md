# Offline spot geometry build

`spot_build.build_source(source_path, output_dir, source, *, budget_check=None)` builds one local pinned source into a new exclusive directory. The source dictionary contains `id`, `url`, `declaredBytes`, `etag`, `expectedVintage`, `licenseUrl`, and `sourcePage`; optional `sha256` verifies the acquired digest. The acquisition layer validates the source dictionary. The builder checks local length and exact replication header vintage, hashes the source, and detects size/mtime changes across processing.

The zero-argument budget callback runs before and after IO and during selection; its exceptions propagate. Failed-stage files stay in the exclusive output directory for supervisor accounting. The runner owns the aggregate 100 MiB budget and supervision. No download or runtime catalog installation occurs here. Source and output paths reject symlinks, junctions and reparse components; existing output directories are refused.

Outputs are canonical `reference.json`, `filtered.osm.pbf`, canonical `candidates.json`, one partition set and `report.json`. Existing category precedence, text cleanup, name fallback and completeness scoring are reused. Every document carries the exact source metadata and pinned vintage. The bounded generic three-pass filter reuses category selection and the existing filter keys, preserving selected ways and available referenced nodes. It bounds selected way IDs at 10,000 and referenced node IDs at 1,000,000 before inserting additional identities. Relations are excluded. Incomplete selected ways and selected ways whose vertex longitude span exceeds 180 degrees are counted with bounded source way IDs and excluded before arithmetic mean acceptance. Repeated closing vertices are removed. Mean vertices are representative points, not entrances or corrected polygon geometry.

The report records canonical reference/filter equality, candidate row count, input hash, geometry dispositions, partition identity/value equality, each partition's rows/bytes/hash and file caps. Reference JSON and filtered JSON are each capped at 4 MiB, filtered PBF at 8 MiB, all partitions combined at 4 MiB and report at 1 MiB. Existing partition limits also bound rows and partition count. A failure raises and leaves accounted scratch; there is no success report for failed work.

Reference/filter equality uses the same point policy in both paths and is explicitly **not independent geometry proof**. Synthetic opposite-longitude, pole, closure and missing-coordinate checks exercise that policy without claiming new geographic coverage. PBF binary serialization may contain library metadata; determinism acceptance concerns canonical candidate and partition bytes. The preserved Bhutan command and constants are unchanged.
