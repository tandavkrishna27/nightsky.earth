# Bounded boundary spatial index — 17 October 2026

The membership classifier now queries a balanced bounding-volume tree before exact containment. This removes the mandatory 4,854-feature visit for every candidate in the retained full-boundary inventory. It does **not** establish global build fit: candidate/lineage/exclusion byte ceilings, geometry work, node count, memory, scratch and time remain finite and unmeasured at planet scale. No limit, identity, source authority or coverage claim changed.

## Behavior and resource bounds

The tree indexes every known and unresolved feature using ordinary longitude/latitude extrema. Both ancestor and leaf boxes use the old strict outside comparisons with the same `1e-10` margin. Possible matches call the unchanged exact `contains` implementation, and returned hits are restored to original feature order. No longitude unwrapping, latitude cutoff or inferred coverage is introduced. Split dateline and multipart features can have wide boxes; false positives cost work and never become memberships without exact containment. Borders, overlaps and unresolved competitors retain their previous unknown behavior.

Each median split reduces the entry count, including identical centres. Depth is O(log N), retained entries/nodes are O(N), and only leaves retain descendant arrays. Repeated sorting costs O(N log² N) construction work; worst-case overlapping boxes still require O(N) query visits and exact geometry work. Vertex bounds, entry/node construction, union passes, native-sort comparisons, traversal, leaf inspection and hit allocation/sorting call the existing shared work/deadline check. Native slices allocate only bounded subsets of the already admitted feature inventory. The 64 MiB boundary allocation, vertex caps, 200-million work cap, 30-minute stage cap, 128 MiB streams, output cap and supervising memory/process limits remain unchanged. Failure leaves no completion marker.

Independent review also found that the fixed production code snapshot omitted membership's executable dependencies. Both TypeScript and Python lists now bind the same **17 files**, including the 12 local transitive membership additions and the existing loader. Changed classifier, geometry, assembly or downstream/schema bytes invalidate a previous admission snapshot; existing retained accounting, leases, per-file one-MiB pin reads and before/after checks apply. This changes snapshot identity and requires regeneration of any old execution envelope. It supplies no additional source review grant.
