## Findings that change the readiness assessment

1. **There is a documented NetCDF-specific constraint, not merely an unspecified possible conversion limit.** The current [ERA5 download guide](https://confluence.ecmwf.int/spaces/CKB/pages/129135000/How%2Bto%2Bdownload%2BERA5%2Bfrom%2Bthe%2BClimate%2BData%2BStore%2BCDS), updated 29 September 2026, points explicitly to this restriction. [ECMWF Support's announcement](https://forum.ecmwf.int/t/limitation-change-on-netcdf-era5-requests/12477), dated 3 April 2025, includes hourly single levels among affected datasets and directs users to validate the selection in its download form. It gives no numeric ceiling in the announcement text. All 16 pinned requests select `data_format:"netcdf"`; a GRIB limit comparison cannot discharge this check.
2. **The largest groups depart from the documented efficiency example.** [CDS documentation](https://confluence.ecmwf.int/spaces/CKB/pages/174856258/Climate%2BData%2BStore%2BCDS%2Bdocumentation) recommends smaller requests and illustrates one calendar month per request, looping through years. Rows 2–14 each combine 8–30 separate years into one parent. This is an efficiency concern, not proof that the service rejects them. The same page's 120,000-field table was last reviewed October 2024, before the NetCDF announcement. No numeric NetCDF ceiling was established from public documentation alone.
3. **The February 2026 area-extraction change does not imply a shifted grid for these boxes.** [ECMWF's area-extraction notice](https://confluence.ecmwf.int/spaces/CKB/pages/621027006/Software%2Bupgrade%2Bfor%2Bgeographical%2Barea%2Bextraction%2Bfrom%2Bdata%2Bon%2Bregular%2Blat-lon%2Bgrids) says extraction now crops existing regular-grid points; a source-grid-aligned southwest corner has zero shift. Both pinned boxes have quarter-degree-aligned corners, positive width/height, and no `grid` key. The [dataset overview](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels?tab=overview) specifies 0.25-degree atmospheric reanalysis. These facts support the intended four-node geometry; response coordinates still require admission checks.
4. **The mixed-grid NetCDF warning does not describe these requests.** The current download guide warns against mixing atmospheric reanalysis, waves and ensemble data in one NetCDF request. The packet selects only reanalysis and total cloud cover. This resolves that particular concern without proving conversion success or output packaging.
