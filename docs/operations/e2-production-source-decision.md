# E2 production source decision — 16 October 2026

Decision proposal against `116e715`, branch `codex/plugin-v1`. This public-document research advances the global/free V1 promise; it does not close S2-E2 or alter runtime contracts. The existing 2025–2027, 38-maximum admission is retained and the completed 2027 report was not requested again. No observation datasets, ephemerides, archives, credentials, external contact or deployment were used. All web references below were inspected on **2026-10-16**; an observation date is not a publication/version date.

## Recommended production direction

Adopt two explicitly different meteor products: source-backed **typical calendar guidance at its published precision**, and **year-specific forecast maxima**. A typical calendar need not pretend to specify physical UTC start/end instants. Propose a reviewed contract extension carrying source wording, calendar precision, recurrence basis, provenance and approximate applicability; keep it distinct from precise event timestamps and measured full-season radiant validity. This would provide useful planning before every scientific conversion question is solved. It is a proposed acceptance/contract change, not an implemented shortcut or a claim that full-season acceptance has passed.

For full-season radiant coverage, select the licensed GMN observational route as the concrete next candidate, subject to a finite sample proposal and explicit scientific design. For eclipse validation, select NASA's explicitly reusable canon documentation and bounded local references; retain the existing finite tolerances until new comparisons establish more.

## Smallest next actions

1. Review a calendar-guidance contract: permit approximate source dates/periods as clearly labeled reference guidance without converting them into event instants. Calendar overlap may be an approximate relevance signal only; it cannot produce a precise active/inactive assertion or expand radiant validity. Retain the broad V1 season/radiant requirement as open until its acceptance wording and evidence are explicitly reviewed. A day-level planning product does not need subminute astronomy accuracy, but still needs source rights and honest boundaries.
2. For the seven missing radiant codes and the full 19-code season union, prepare one GMN sample design before any acquisition: exact codes, observation interval, asset identity/size, quality cuts, assignment version, minimum evidence/missingness rules, treatment of station exposure and background, declared activity threshold, drift-fit validity and out-of-sample checks. Report an empirical observed activity interval with its method; never label first/last observed meteor a physical season. Radio/daytime showers may require another measurement route. No unseen sample size or coverage guarantee is asserted here.
3. Retain existing admitted maxima and manual annual admission procedure in [E2 delivery](e2-retained-acceptance-delivery.md). The next new annual question is 2028. Typical guidance, if approved, can coexist with explicit unavailable year-specific maxima; no dates are shifted from 2025–2027.
4. Before expanding the eclipse accepted horizon, choose a finite production year range and a small independent reference matrix covering solar/lunar classes, both hemispheres, horizon crossings and unresolved grazing. Retain exact location, altitude/refraction convention, model, ΔT, clock, source precision and justified tolerances. NASA canon cases plus existing JPL AIRLESS references are concrete sources; acquire only the later authorized finite reference packet. Do not use one city or global greatest-eclipse values to certify arbitrary local contacts.

## Acceptance boundary

Current counts and explicit missing-code sets remain those in [S2 events coverage](s2-events-coverage-matrix.md): 19 combined meteor codes, zero accepted complete UTC seasons, seven missing radiant fits, and missing year/code maxima. These are retained facts, not newly downloaded results. Global access and practical approximate guidance remain the product objective. Precise season conversion, full-season radiant support and arbitrary-year eclipse accuracy remain unproved. Unsupported cases remain visible rather than silently disappearing from discovery.
