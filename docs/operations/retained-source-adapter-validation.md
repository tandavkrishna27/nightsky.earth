# Retained source adapter validation

`validate-retained-source-adapters.ts` is an offline, read-only consistency report. It changes no registry or release. Every result has `sourceAdmitted: false` and `nativeParserRerun: false`. Passing means the named local contract was checked; it does not mean a source family, rights decision, clipping footprint or worldwide edition was admitted. A synthetic fixture can satisfy a normalized contract and still supply no real source evidence.

Run `node --import tsx scripts/validate-retained-source-adapters.ts PLAN.json PLAN_SHA256`. The plan is strict JSON `{ "schemaVersion": 1, "entries": [...] }`, with 1–16 entries. The SHA-256 is an independently reviewed pin, not a value discovered from the plan itself. Exit 0 means every requested local check passed; exit 2 means a contract rejected. Findings expose only fixed adapter/status/code fields, never paths, source properties, raw exceptions or credentials. Unsupported ARCO or gbOpen adapter names reject. Both families remain explicitly `not-admitted` in plan reports.

All file pins are `{path, bytes, sha256}` with exact integer bytes and lowercase SHA-256. Paths are relative to the plan directory, without traversal, backslashes, absolute paths or colons; the existing catalogue safe-path guard also rejects symbolic links and ambiguous Windows paths. Read handles check file type, size, hash and before/after identity. Inputs require an externally immutable local snapshot when concurrent writers are untrusted; sampled metadata checks do not remove every filesystem race. The plan is at most 64 KiB, reports at most 1 MiB, normalized/decoded bodies at most 4 MiB and raw bodies at most 32 MiB. Work is sequential and bounded. There is no parser subprocess, decoder fallback, network or output writer.

## Explicit adapters

| Adapter | Required fields in addition to `adapter` | What is checked |
| --- | --- | --- |
| `retained-osm-regional-v1` | `raw`, `manifest`, `candidates` pins; `nativeVintage`, exact `sourceUrl`, `rights`, `extraction` | Actual raw byte pin; owning `osmCandidateIndexSchema`; retained offline extractor completion/exit code, input/output pins and candidate count; matching manifest/artifact/source vintage; ODbL URL and matching attribution; exact extraction limitations. Native PBF vintage is the retained producer's statement, not a fresh header decode. |
| `retained-osm-canonical-v1` | `completion` pin, `catalogueRevision`, `manifestSha256`, `sources` | Strict owning `global_source.py` completion format and actual three output bodies; owning catalogue candidate schema; unique candidate/lineage identities, per-source hashes/vintages/policy, source URL/rights/product and every candidate's source linkage. This adapter does **not** reopen raw PBFs or the manifest. Expected manifest identity and source pins must come from the separately retained owning producer run. |
| `retained-era5-monthly-v1` | `raw`, `decoded`, `inspection` pins; `rights`, `firstUtc`, `lastUtc`, `experimentVersions`, `cells` | Actual raw byte pin; owning `parseDecodedChunk`; typed retained inspection metadata; raw hash, final revision `0001`, deterministic member 0, fractional `cloud_area_fraction`, valid_time/latitude/longitude dimension order and sizes, count, actual supplied cells, calendar/time units, endpoint timestamps and contiguous decoded hourly rows. Scientific values are validated by the owning decoded-row parser. |
| `normalized-boundary-v1` | `geometry` pin and `evidenceClass` (`synthetic` or `retained-normalized`) | Owning `boundaries` parser with 100,000 vertices/1 million comparisons; Polygon/MultiPolygon rings, holes/islands and split dateline rules. No membership or extraction coverage inference; `validated-normalized` is never gbOpen admission. |

`rights` is exactly `{licenseUrl, attribution}`. Regional OSM `extraction` is exactly `{incompleteWays: integer >= 0, relationsPolicy: "excluded", wayPointPolicy: "mean complete vertices, closing vertex removed"}`. These are limitations, not completion claims. Canonical source rows are exactly `{id, sha256, nativeVintage, url, rights}`; ODbL and `© OpenStreetMap contributors` must match the owning canonical producer. Canonical policy is `named-complete-way-v1-polar85`: relations/unnamed/incomplete/dateline/polar/invalid geometry exclusions retain their own records. Completion coverage must literally remain `unknown; clipping metadata is not coverage`. A synthetic clip-control hash is never promoted to clipping evidence. Empty normalized files are supported.

ERA5 `cells` preserves actual array order and each row is exactly `{cellId, latitude, longitude}`, on the decoder's quarter-degree grid. `experimentVersions` must be exactly `["0001"]`. Initial revision/ERA5T and an arbitrary source claiming the same data class do not pass native-source admission: there is no native-source admission path here. Header/source `dataClass` is constrained by the owning schema, and inspection `data_class` must be the retained historical-hourly-reanalysis label. Inspection proof booleans such as `checks.hourly_contiguous` are ignored; actual decoded rows establish contiguity. Time and dimension values must be numbers with bounded integer sizes; string coercion is refused. Monthly support is deliberately narrow: grouped multi-year decoded streams and alternative legacy time-axis formats are not silently accepted. ERA5 rights fields are explicit operator declarations because the retained decoder/inspection format has no embedded licence record; this checker cannot establish licence acceptance or derivative publication permission.

## Evidence and remaining compatibility gaps

The Bhutan retained extractor evidence describes a 23,618,779-byte PBF with SHA-256 `6728f46b23ab722d9713af1b4a089d7c62290d9b28baa1fcb4348cd4afd1ba87`, vintage `2026-10-12T20:21:35Z`, and 134 candidate rows. The retained manifest and extraction policy were inspected as small local metadata; this adapter work has not rescanned that PBF. The retained Hanle January 2025 inspection/header describes raw SHA-256 `e674bae1ee78a1a7126b5d3470b74298b9dd828efc68282901b8cbebfaaad039`, 80,862 raw bytes, revision `0001`, 744 hours and four supplied cells. Metadata declarations alone do not establish a new decode. The report makes that distinction explicit rather than interpreting any caller-provided success flag as proof.

No real gbOpen geometry/metadata body or ARCO/time-series body has been acquired or admitted by this lane. The normalized geometry fixtures are synthetic controls. The format references already retained in [production-data-build-decision.md](production-data-build-decision.md) and [production-history-build-proposal.md](production-history-build-proposal.md) are documentation evidence only. The previously retained [official ARCO/time-series guide](https://confluence.ecmwf.int/spaces/CKB/pages/505390919/ERA5%2Bhourly%2BAnalysis%2BReady%2BCloud%2BOptimised%2BARCO%2Bdata%2Bon%2Bsingle%2Blevels%2Bfrom%2B1940%2Bto%2Bpresent%2BProduct%2BUser%2BGuide%2BPUG) describes total_cloud_cover (0–1), nearest quarter-degree point/limited-area time-series requests and NetCDF/CSV output. These facts do not settle actual variable names, dimension order, revisions, missing encoding or response packaging. No guessed decoder is implemented. The previously retained [geoBoundaries API reference](https://www.geoboundaries.org/api.html) identifies the family; an exact immutable edition and actual body compatibility remain missing. No links were fetched for this work.

## First future acquisition packet (proposal only)

Before any new acquisition, prepare one independently reviewable packet with an immutable source edition and exact URL/request, explicit authorization, declared upper bounds for requests/transfer/raw bytes/decoded bytes/time/RSS/scratch, abort behavior and exclusive local staging identity. Keep rights/attribution and native vintage distinct from retrieval time.

For geography, choose one gbOpen ADM0/ADM1 country pair at one commit, list both metadata and full-geometry bodies separately with expected identifiers/rights, enumerate missing levels and simplification/dispute flags, and predeclare tests for native properties, holes/islands, borders and dateline/polar behavior. Actual OSM clipping body/hash and extraction policy must be separately reviewed; neither administrative geometry nor the current synthetic clipping control establishes source extraction completeness.

For history, choose one final ERA5 time-series month and supplied cell, settle the precise product/revision guarantee and supported response format from the approved request, retain the raw response and metadata/rights lineage, and budget an owning decoder inspection that records exact variable, units, dimension names/order/counts, cell coordinates, time units/calendar/missing values/member/revision. Compare actual decoded rows with a retained legacy CDS control for that exact cell/time and record transfer amplification. A decoder implementation decision follows the actual retained format inspection. This packet does not authorize account access, requests, store metadata reads, provider calls or publication.

## Minimal reviewable plan shape

This complete boundary-control example is deliberately synthetic. Replace the two placeholders with independently measured local file values before use; it cannot establish source admission.

```json
{"schemaVersion":1,"entries":[{"adapter":"normalized-boundary-v1","geometry":{"path":"controls/regions.geojson","bytes":123,"sha256":"<64 lowercase hex>"},"evidenceClass":"synthetic"}]}
```

For a canonical producer report, the entry shape is:

```json
{"adapter":"retained-osm-canonical-v1","completion":{"path":"normalized/complete.json","bytes":123,"sha256":"<64 lowercase hex>"},"catalogueRevision":"<exact owning producer revision>","manifestSha256":"<exact owning producer manifest digest>","sources":[{"id":"monaco","sha256":"<raw source digest>","nativeVintage":"2026-10-13T20:20:53Z","url":"https://example.invalid/exact-dated-source.osm.pbf","rights":{"licenseUrl":"https://opendatacommons.org/licenses/odbl/1-0/","attribution":"© OpenStreetMap contributors"}}]}
```

That source URL/vintage are illustrative fields, not newly acquired or admitted evidence. The actual canonical producer completion check remains pending the separate retained measurement lane's completion/stop; absence of a completed output is preserved as unavailable rather than manufactured from fixtures. API callers may use `validateRetainedAdapter(baseDirectory, unknownEntry)` for one redacted finding or `validateRetainedPlan(planPath, expectedPlanSha256)` for the full report. `retainedAdapterSchema` and `retainedValidationPlanSchema` are exported strict descriptor schemas.
