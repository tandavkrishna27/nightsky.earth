| Planet-pair ecliptic-longitude conjunction | `PairLongitude` (`astronomy.d.ts` lines 1290–1321; implementation 4247–4256) returns geocentric relative longitude. For planets it uses light-time-corrected `GeoVector(..., false)` (**aberration disabled**) then `Ecliptic` (2731–2744), true ecliptic/equinox of date. It is not the same correction convention as `AngleFromSun`. No dedicated general planet-pair event search is exported in this version. | A finite declared planet-pair set could use those local vectors and a bounded root search for equal longitude. Choose/label ecliptic equality versus RA equality versus minimum 3D separation before implementation, then retain matching independent cases, including wrap/repeated-event behavior. Those definitions are not interchangeable. |

Greatest elongation is therefore a small feasible **local-calculation** addition to an already named scope example, with a finite reference/contract gate. General planet-pair conjunction discovery needs more definition and bracketing work; a local path is feasible but not a one-line call to the existing heliocentric alignment function. Neither requires a new remote ephemeris runtime or bulk catalogue. No scope expansion or unreviewed numerical implementation is performed here; actual local visibility/darkness/detectability remains a separate calculation and claim.
